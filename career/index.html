Resume rules

  • Single column, standard headers, PDF. The "75% ATS auto-reject" stat is a debunked myth — the real filters are parsing corruption, human skimming, and applying late.
  • Every bullet: "Accomplished X, measured by Y, by doing Z." Use $ project value, SF, # buildings, hours saved.
  • Track A variant: experience-first, mirror posting vocabulary (modular, DfMA, mission-critical, tilt-up, owner's engineer). Track B variant: projects-first.
  • Apply in the first days of a posting; pair every application with a human touch.

H-1B → green card

The visa thread (runs under everything)

  • Transfers are safe: in-country H-1B change-of-employer petitions are exempt from the $100k new-petition fee and need no lottery. Many recruiters don't know this — say it: "H-1B transfer — no lottery, no $100k fee exposure."
  • The fee helped you: it concentrated H-1B hiring into big tech — your Track A targets.
  • File EB-2 NIW now: structural engineers doing infrastructure-safety + AI work have documented approvals; it frees you from employer-tethered PERM and locks a priority date.
  • Build EB-1A/O-1 evidence deliberately (if India-born, the EB-2 queue is 15–25 yrs — EB-1 is the exit): publications (STRUCTURE, ASCE), open-source adoption, hackathon awards, talks, peer review, code committees. Every Track B artifact counts twice.
  • No 1099 side income on H-1B — expert-witness and consulting work must wait or run W-2 through an employer like Exponent.
